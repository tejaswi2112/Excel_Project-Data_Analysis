# 📊 Excel Data Analysis Projects

> 🔍 A portfolio of Excel-based projects exploring the **2023 data science job market** — uncovering salary trends, high-value skills, and regional pay gaps. Each project showcases a distinct tier of Excel proficiency, from interactive dashboards to advanced data modeling.

---

## 📁 Projects

---

### 🗂️ [Project 1 — Salary Dashboard](./Project_1-Dashboard/)

> 💼 *Built for job seekers who want to know their worth.*

An interactive Excel dashboard that lets users explore and compare salaries across data roles, countries, and job schedule types — all with dynamic dropdowns and live-updating charts.

#### ✨ Key Features
- 📊 **Bar Chart** — Ranks job titles by median salary for instant comparison
- 🗺️ **Map Chart** — Visualizes salary distribution across countries with color coding
- 🔽 **Dynamic Dropdowns** — Filter by job title, country, and schedule type via data validation
- 🧮 **Array Formula** — Multi-criteria `MEDIAN(IF(...))` for precise, tailored salary lookups

#### 🛠️ Excel Skills
`📉 Charts` &nbsp;|&nbsp; `🧮 Formulas & Functions` &nbsp;|&nbsp; `❎ Data Validation`

#### 💡 Key Insight
> Senior roles and Engineers consistently out-earn Analyst roles — and location plays a significant role in that gap.

---

### 🗂️ [Project 2 — Market Analysis](./Project_2-Analysis/)

> 🧠 *A data-driven answer to: "What skills should I learn, and what will they pay?"*

A deep-dive analytical project that answers four real questions about the data science job market using Power Query, DAX, and advanced pivot techniques.

#### ❓ Questions Explored
1. 💰 Do more skills get you better pay?
2. 🌍 What's the salary for data jobs in different regions?
3. 🏆 What are the top skills of data professionals?
4. 📈 What's the pay for the top 10 skills?

#### ✨ Key Features
- 🔄 **Power Query (ETL)** — Extracted, cleaned, and loaded two separate data tables
- 🔗 **Power Pivot** — Built a relational data model linking jobs and skills via `job_id`
- 🧮 **DAX Measures** — Calculated global and US-specific median salaries
- 📊 **Combo Pivot Chart** — Plotted median salary vs. skill likelihood on dual axes

#### 🛠️ Excel Skills
`📊 Pivot Tables` &nbsp;|&nbsp; `📈 Pivot Charts` &nbsp;|&nbsp; `🧮 DAX` &nbsp;|&nbsp; `🔍 Power Query` &nbsp;|&nbsp; `💪 Power Pivot`

#### 💡 Key Insights
> - 📈 More skills = higher pay — especially for Senior Data Engineers and Data Scientists
> - 🐍 **Python** and **SQL** dominate as the most in-demand skills across all data roles
> - ☁️ Cloud skills (AWS, Azure) are surging in demand
> - 💸 Python, Oracle, and SQL are tied to the highest median salaries
